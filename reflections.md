Reflections
The biggest challenge for me on this project was Bootstrap. I'm still getting used to figuring out what I should let Bootstrap handle and what I need to do with custom CSS. I was able to use the Bootstrap grid to make the two cards sit beside each other on desktop and stack on mobile, but getting the design itself to match the reference took more work. The mobile proportions still aren't as accurate as I would like them to be. This project was also more difficult without access to the Figma file. I've gotten used to being able to inspect exact measurements, spacing, and sizing in Figma instead of guessing from an image. I approached the project by getting the main layout working first and then working through the individual design details. If I had more time, I would focus mostly on getting the mobile proportions closer to the original design.
